## 第一章：什么是区块链

### 1.1 用银行账本来理解区块链

想象一下传统银行：

```
传统银行账本（中心化）：
┌─────────────────┐
│     银行        │  ← 只有银行能修改账本
│   ┌─────────┐   │
│   │ 账本    │   │
│   │张三: 100│   │
│   │李四: 50 │   │
│   └─────────┘   │
└─────────────────┘
```

区块链账本（去中心化）：
```
区块链账本：
┌─────────┐  ┌─────────┐  ┌─────────┐
│ 节点A   │  │ 节点B   │  │ 节点C   │  ← 每个人都有相同的账本
│ 账本副本│  │ 账本副本│  │ 账本副本│
│张三:100 │  │张三:100 │  │张三:100 │
│李四: 50 │  │李四: 50 │  │李四: 50 │
└─────────┘  └─────────┘  └─────────┘
```

### 1.2 区块链的核心特点

1. **去中心化**：没有银行，大家共同维护账本
2. **透明**：所有交易记录公开可查
3. **不可篡改**：一旦记录，很难修改
4. **全球通用**：24小时运行，无地域限制

## 第二章：什么是以太坊

### 2.1 以太坊 = 世界计算机

```
传统计算机：
┌─────────────────┐
│   你的电脑      │
│ ┌─────────────┐ │
│ │   程序      │ │  ← 只能在你的电脑上运行
│ └─────────────┘ │
└─────────────────┘

以太坊：
┌─────────┐  ┌─────────┐  ┌─────────┐
│ 节点A   │  │ 节点B   │  │ 节点C   │
│ 智能合约│  │ 智能合约│  │ 智能合约│  ← 程序在全球成千上万台电脑上运行
│ 程序    │  │ 程序    │  │ 程序    │
└─────────┘  └─────────┘  └─────────┘
```

### 2.2 智能合约：自动执行的程序

## 第九章：数据格式基础

### 9.1 十六进制数字

```javascript
// 我们平时用十进制（0-9）
const 十进制 = 255;

// 计算机常用十六进制（0-9, A-F）
const 十六进制 = "0xFF";  // 和255相等

// 转换对照表
const 对照表 = {
    10: "A", 11: "B", 12: "C",
    13: "D", 14: "E", 15: "F"
};

// 为什么用十六进制？
// 1. 更紧凑：255用十六进制只需要2位（FF）
// 2. 便于计算机处理：1字节 = 2个十六进制字符
```

### 9.2 字节和地址

```javascript
// 1字节 = 8位 = 2个十六进制字符
const 字节示例 = {
    "1字节": "FF",           // 255

    "20字节": "dac17f958d2ee523a2206206994597c13d831ec7"  // 以太坊地址
};

// 以太坊地址解析
const 地址解析 = {
    完整地址: "0xdac17f958d2ee523a2206206994597c13d831ec7",
    分解: {
        前缀: "0x",  // 表示这是十六进制
        实际地址: "dac17f958d2ee523a2206206994597c13d831ec7",  // 40个字符 = 20字节
        字节数: 20
    }

```
